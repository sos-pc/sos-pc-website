1.5 Plan cold start — construire la credibilite sans references

Sans portfolio client au depart, Talos Int. s'appuie sur une strategie de preuve technique immediate :

  • GitHub public configurations homelab, templates Docker Compose, scripts n8n commentes en francais. Pour un client technique, c'est plus convaincant que 10 avis.
  • Site Talos Int. comme premiere demo site rapide, bien heberge, bien deploye. Si le cordonnier est bien chausse, le client comprend sans mot.
  • 2-3 cas d'usage documentes un site gite fictif, un dashboard n8n, une config RGPD anonymisee — presentes comme demos sur le site.
  • LinkedIn professionnel profil optimise avec titre : 'Solutions numeriques souveraines · n8n · Self-hosting · RGPD'. 1 post/semaine, format : probleme → solution → resultat.
  • Formation DPO via CPF certification Delegue a la Protection des Donnees, finançable via CPF (800-2 000 EUR pris en charge). Planifiee en M3-M6 pour credibiliser la niche sante.
